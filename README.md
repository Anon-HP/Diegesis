# English Comic Panel-Transition Classifier (McCloud's six categories)

Give it **two consecutive panel images** from an originally-English Western comic (Panel A, then Panel B).
It returns **exactly one** of Scott McCloud's six transition types, plus a confidence score:

`moment-to-moment` · `action-to-action` · `subject-to-subject` · `scene-to-scene` · `aspect-to-aspect` · `non-sequitur`

> **Status: working inference system, weak classifier.** On held-out books it scores macro-F1 0.39
> over the three well-supported classes (majority baseline 0.17). Its accuracy (0.375) is **not**
> distinguishable from always predicting the most common class (0.353). All labels were generated by
> an LLM (Claude), not by people. Read [`docs/limitations.md`](docs/limitations.md) before using it.

## Quick start

```bash
# one-time setup (Python ≥ 3.12; developed on 3.14, Linux, GTX 1650)
sudo apt install tesseract-ocr            # English OCR, used internally on the two images
python3 -m venv .venv
.venv/bin/pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126   # or the CPU wheel
.venv/bin/pip install -r requirements.txt

# predict
.venv/bin/python predict.py panel_A.jpg panel_B.jpg
# -> action-to-action	0.615

.venv/bin/python predict.py panel_A.jpg panel_B.jpg --json   # all 6 probabilities + internal OCR text
.venv/bin/python predict.py panel_A.jpg panel_B.jpg --cpu    # force CPU
```

- The first run downloads OpenCLIP ViT-B/16 (about 600 MB) and DINOv2 ViT-B/14 (about 350 MB) into `$HF_HOME` (default `workspace/hf_cache`).
- One prediction takes about 2 s once the models are loaded. A cold CLI start takes about 25–30 s, most of it
  model loading and Tesseract.
- Inputs are validated. A missing file, an unreadable image or an image under 32 px exits with code 2. The
  classifier needs nothing except the two images: no page, no other panels, no metadata.
- If `models/head.joblib` is missing, the CLI falls back to an untrained heuristic and says so in the `method` field.

## Web app (local)

There is a browser UI in `frontend/` (Next.js), backed by a local inference API (`serve.py`, FastAPI).
Nothing is deployed anywhere; both run on your machine.

```bash
# terminal 1: inference API on http://127.0.0.1:8000 (loads the model, ~20 s)
.venv/bin/python serve.py

# terminal 2: web UI on http://localhost:3000 (Node ≥ 20; pnpm 12, e.g. `npm i -g pnpm@12.3.4`)
cd frontend
pnpm install --frozen-lockfile
pnpm build && pnpm start          # or `pnpm dev` while editing
```

- Open <http://localhost:3000>, upload Panel 01 and Panel 02 (PNG or JPEG, up to 15 MB each), and click
  **Analyze transition**.
- The page shows the predicted McCloud type, the model's confidence, the probabilities for all six types,
  and warnings: low confidence, the unreliable non-sequitur class, or a missing trained head.
- The browser only talks to `:3000`. Next.js proxies `/api/*` to the Python server; set `BACKEND_URL` to
  change the target.
- API: `GET /api/health`, and `POST /api/analyze` (multipart fields `first`, `second`). Errors come back as
  `{"error": {"code", "message"}}` with status 400/413/503/500, and the UI displays the message.

## How it works

The encoders are frozen, and a small classifier head sits on top. See [`docs/model_design.md`](docs/model_design.md).

1. Each panel goes through the OpenCLIP ViT-B/16 image embedding, DINOv2 patch tokens, Tesseract OCR and
   low-level image statistics.
2. Pair features are built from these:
   - CLIP difference/product features.
   - Mean-centred CLIP/DINO cosines.
   - DINOv2 patch-matching statistics.
   - CLIP zero-shot "shot type" scores (close-up, establishing shot, caption box…) for both panels.
   - Image statistics.
   - Caption-cue lexicon features from OCR.
3. A class-balanced logistic regression on PCA-reduced features gives one of the six labels.

## Results (held-out test books, single evaluation)

All test labels are LLM labels (`label_source=llm`). The numbers measure agreement with the LLM annotator.

| Model | Macro-F1 (action/subject/scene) | Macro-F1 (present classes) | Balanced accuracy | Accuracy |
|---|---|---|---|---|
| **Deployed model** (`logreg_pca \| clipdiff+zs+cos_c+match+low+cue2`) | **0.394** (95% CI 0.32–0.47) | 0.236 | 0.232 | 0.375 (CI 0.31–0.46) |
| Rule baseline (hand thresholds) | 0.304 | 0.182 | 0.216 | 0.331 |
| Majority class | 0.174 | 0.104 | 0.200 | 0.353 |

- The test split has 136 natural pairs from 31 books that were never used for training or model
  selection. Confidence intervals come from resampling by book.
- Per-class test F1: action 0.52, scene 0.36, subject 0.31, moment 0.00 (3 examples), aspect 0.00
  (1 example). There are no natural non-sequiturs in the test split.
- Full numbers, confusion matrices and every configuration tried are in `experiments/r3_cv.json`,
  `experiments/r3_cv_test_predictions.csv` and [`experiments/README.md`](experiments/README.md).

## Data and labels

- **Comics:** the COMICS dataset (Iyyer et al. 2017): US Golden Age comics from 1938–1954, originally in English.
  Only the first 3.5 GB of the 65 GB panel archive was used: 204 books and 62,029 consecutive pairs. Images
  are never committed. See [`docs/data_sources.md`](docs/data_sources.md).
- **Labels:** no public McCloud-labelled Western dataset exists, so labels were created here by Claude
  annotators following [`docs/annotation_guidelines.md`](docs/annotation_guidelines.md).
  - 880 pairs were annotated: 788 are valid natural pairs (action 291, subject 311, scene 156,
    moment 25, aspect 4, non-sequitur 1), and 92 were marked invalid (ads, bad crops, text pages).
  - 88 synthetic cross-book non-sequiturs were added as weak supervision.
  - Every row of [`data/manifest.csv`](data/manifest.csv) records its provenance.
  - Two independent LLM annotators agree on 75.5% of 147 pairs (κ = 0.64).
- **Making it better:** label pairs yourself with the human annotation page (LLM labels hidden by default).
  Human labels automatically take precedence:
  ```bash
  python3 scripts/make_human_annotation_page.py        # open annotations/human_annotation_tool.html
  # save the downloaded CSV into annotations/human/, then:
  python3 scripts/build_manifest.py && .venv/bin/python scripts/extract_features.py
  .venv/bin/python scripts/train.py --exp my_run --final-test --deploy
  ```

## Reproducing the pipeline

Every long-running step is resumable. Ctrl-C or SIGTERM finishes the current unit and exits 130, and
re-running the same command resumes it.

```bash
scripts/fetch_comics_part.sh 3500000000                                    # first 3.5 GB of the archive
tar -xzf …/raw_panel_images.part.tar.gz --skip-old-files                   # into $CPT_WORKSPACE/data/comics/panels_dl
python3 scripts/build_pair_index.py --partial-book 1450                    # 62,029 pairs, splits by book
python3 scripts/sample_for_annotation.py --n 240 --per-book 6 --batch-size 40 --tag r1          # round 1
python3 scripts/sample_for_annotation.py --n 480 --per-book 5 --batch-size 40 --tag r2 --seed 21 \
        --exclude annotations/sample_r1.csv --quota 0.5,0.1,0.1,0.1,0.2                         # round 2
.venv/bin/python scripts/mine_clip_similarity.py && .venv/bin/python scripts/mine_rare_candidates.py --n 160 --per-book 2 --tag r3   # round 3
#   … annotate (annotations/ANNOTATOR_PROMPT.md) …
python3 scripts/build_manifest.py --n-synthetic 100
.venv/bin/python scripts/ocr_cache.py && .venv/bin/python scripts/extract_features.py
.venv/bin/python scripts/train.py --exp r3_cv --models logreg,logreg_strong,logreg_pca --subsets "…" --final-test --deploy
.venv/bin/python -m pytest -q                                               # unit + API + model e2e tests (ui excluded by default)
.venv/bin/python -m pytest -q -m ui                                         # browser tests (needs both servers + Playwright)
```

Large files (panels, caches, model weights) go in a workspace folder: `workspace/` inside the repo by default
(git-ignored). To keep them on another disk, make `workspace` a symlink or set `CPT_WORKSPACE=/path/to/dir`.
